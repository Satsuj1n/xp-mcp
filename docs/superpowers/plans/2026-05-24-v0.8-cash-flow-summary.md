### What to add to the repo

A new exported function next to `listCashFlows`:

```ts
/**
 * List cash flow rows with flow_date >= dateFrom, ordered by
 * flow_date ASC then id ASC. Unbounded (no LIMIT) — intended for
 * service-layer aggregation over a known-bounded window (e.g. 12
 * months of personal cash flows is small).
 *
 * `dateFrom` must be an ISO date string `YYYY-MM-DD`.
 */
export function listCashFlowsSince(
  db: Database,
  dateFrom: string,
): CashFlowRow[] {
  return db
    .prepare(
      `SELECT id, flow_datetime, flow_date, kind, amount_cents,
              description, import_id
         FROM cash_flows
         WHERE flow_date >= ?
         ORDER BY flow_date ASC, id ASC`,
    )
    .all(dateFrom) as CashFlowRow[];
}
```

### Module skeleton

```ts
import { round2 } from "./money.js";
import type { CashFlowRow } from "../storage/cash-flows-repo.js";

export interface CashFlowSummary {
  as_of_date: string;
  total_records: number;
  ytd: {
    year: number;
    aporte_brl: number;
    resgate_brl: number;
    net_brl: number;
  };
  rolling_12m: {
    from_month: string;
    to_month: string;
    months_with_data: number;
    aporte_brl: number;
    resgate_brl: number;
    net_brl: number;
    monthly_avg_aporte_brl: number;
    monthly_avg_net_brl: number;
  };
}

/**
 * Compute YTD and rolling-12-month aggregates from cash flow rows.
 *
 * `asOfDate` is an ISO date `YYYY-MM-DD` that anchors both windows:
 *  - YTD: rows with flow_date in [`${year}-01-01`, asOfDate]
 *  - rolling 12m: rows with flow_date in [first day of (month-11),
 *    asOfDate]
 *
 * Caller is expected to have loaded rows since the rolling window
 * start. Rows outside the window are silently ignored (the function
 * does not assume the caller filtered tightly — it filters too).
 *
 * `monthly_avg_*` divides by `months_with_data` (not by 12) so a
 * short history is not penalised. When `months_with_data === 0`,
 * averages are 0 (no division by zero).
 */
export function computeCashFlowSummary(
  rows: readonly CashFlowRow[],
  asOfDate: string,
): CashFlowSummary {
  // 1) Derive YTD start and rolling window from asOfDate
  // 2) Two passes (or one pass with two accumulators) over rows
  // 3) Track distinct months via Set<string> on flow_date.slice(0, 7)
  // 4) Compute averages with the guard
  // 5) Return shaped result
}
```

The body is the subagent's responsibility — keep it pure, no Date
parsing other than `flow_date.slice(...)` lexicographic ops, no
external dependencies beyond `round2` and the row type.

### Date arithmetic (lift this into the implementation)

```ts
function ytdStart(asOfDate: string): string {
  return `${asOfDate.slice(0, 4)}-01-01`;
}

function rollingWindow(asOfDate: string): {
  fromMonth: string; // "YYYY-MM"
  toMonth: string;   // "YYYY-MM"
  startDate: string; // "YYYY-MM-01"
} {
  const year = parseInt(asOfDate.slice(0, 4), 10);
  const month = parseInt(asOfDate.slice(5, 7), 10); // 1..12
  // 11 months back
  let fromMonthIdx = month - 11;
  let fromYear = year;
  if (fromMonthIdx < 1) {
    fromMonthIdx += 12;
    fromYear -= 1;
  }
  const fromMonth = `${fromYear}-${String(fromMonthIdx).padStart(2, "0")}`;
  const toMonth = `${year}-${String(month).padStart(2, "0")}`;
  return { fromMonth, toMonth, startDate: `${fromMonth}-01` };
}
```

12 cases (one `test(...)` block each):

1. **Happy path: mixed APORTE/RESGATE across multiple months**
   - 3 months of data: Jan/Feb/Mar 2026, asOfDate `2026-03-15`
   - Aporte 1000 BRL, 1500 BRL, 2000 BRL; Resgate 500 BRL in Feb
   - Assert YTD totals, rolling totals (same as YTD here),
     `months_with_data: 3`, averages

2. **Empty rows array**
   - `rows = []`, asOfDate `2026-05-24`
   - Assert all totals 0, `months_with_data: 0`, both averages 0,
     `total_records: 0`, `ytd.year: 2026`

3. **All rows older than 12M window**
   - asOfDate `2026-05-24` → rolling start `2025-06-01`
   - Row on `2025-05-31` → outside window, ignored
   - Assert totals 0, `months_with_data: 0`, `total_records: 0`
     (because rows outside window are not counted in
     `total_records` — only rows in window count)

4. **All rows YTD but rolling broader** (sanity)
   - asOfDate `2026-06-15` → rolling `2025-07` to `2026-06`
   - Row on `2026-05-01` is in both YTD and rolling
   - Row on `2025-12-01` is in rolling but NOT YTD
   - Assert YTD ≠ rolling totals

5. **Single month with multiple rows**
   - asOfDate `2026-05-24`
   - 3 rows all on `2026-05-15`
   - Assert `months_with_data: 1`, average == sum-of-month

6. **Month-boundary: row exactly on rolling start qualifies**
   - asOfDate `2026-05-31`, rolling start `2025-06-01`
   - Row on `2025-06-01` → in window
   - Assert it's counted

7. **Month-boundary: row one day before rolling start is excluded**
   - asOfDate `2026-05-31`, rolling start `2025-06-01`
   - Row on `2025-05-31` → outside
   - Assert it's NOT counted, `total_records: 0`

8. **January asOfDate**
   - asOfDate `2026-01-15`
   - 1 row on `2026-01-10` → in YTD
   - 1 row on `2025-12-15` → in rolling, NOT in YTD
   - Assert YTD has only the Jan row; rolling has both

9. **Cross-year rolling window**
   - asOfDate `2026-02-28`, rolling = `2025-03` to `2026-02`
   - Rows in Dec 2025 and Jan 2026 → both in rolling
   - Assert `from_month: "2025-03"`, `to_month: "2026-02"`

10. **Resgate-only month → negative net**
    - asOfDate `2026-05-24`
    - 1 row: `2026-04-15` RESGATE 5000 BRL
    - Assert `aporte_brl: 0`, `resgate_brl: 5000`, `net_brl: -5000`

11. **Rounding: odd cents → BRL with 2 decimals**
    - asOfDate `2026-05-24`
    - 1 row: APORTE `123456` cents (R$ 1234.56)
    - Assert `aporte_brl: 1234.56`

12. **Large numbers: no float drift**
    - asOfDate `2026-05-24`
    - 3 rows summing to R$ 1_000_000 exactly (e.g. 333_333_33 + 333_333_34 + 333_333_33 = 99_999_900 cents)
    - Assert sum is R$ 999_999.00 (or whatever the exact value is —
      the point is no precision loss)

### `get-portfolio-summary.ts` changes

```ts
import { listCashFlowsSince } from "../storage/cash-flows-repo.js";
import { computeCashFlowSummary } from "../services/cash-flow-summary.js";

export async function getPortfolioSummary(
  _input: GetPortfolioSummaryInput,
  deps: GetPortfolioSummaryDeps = {},
): Promise<PortfolioSummary> {
  const db = deps.db ?? getDb();
  const positions = listPositions(db);
  const lastDeclared = getLastDeclaredImport(db);

  // Compute today's date and rolling window start
  const asOfDate = new Date().toISOString().slice(0, 10);
  // Derive rolling start the same way as in the service — duplicate
  // the helper inline, OR export it from the service. Prefer export
  // (avoids drift).

  const cashFlowsSince = listCashFlowsSince(db, rollingStart);
  const cashFlowSummary =
    cashFlowsSince.length === 0
      ? null
      : computeCashFlowSummary(cashFlowsSince, asOfDate);

  return computePortfolioSummary(positions, lastDeclared, cashFlowSummary);
}
```

**Decision required of subagent:** export `rollingWindow` (or a
small `ytdAndRollingStart` helper) from
`services/cash-flow-summary.ts` rather than duplicating the date
math in the tool. The tool just needs `rollingStart` to know what to
fetch.

**Optional deps:** to keep deterministic tests, accept an optional
`now: Date` in `deps` (default `new Date()`). Pattern matches how
other tools take `db` injection. This is what the new integration
tests will use.
