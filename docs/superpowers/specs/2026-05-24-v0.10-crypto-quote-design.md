## 1. Why

Open TODO (2026-05-20): *"Adicionar suporte a cripto (novo
`MarketDataSource` adapter — Binance / Mercado Bitcoin / Foxbit)."*

The portfolio today does not track crypto positions — `asset_class` has
no `CRIPTO` member and there is no crypto import path. Making crypto a
first-class tracked asset (Scope B) would require a schema migration,
an import path whose source format is undefined, and integration into
summary/drift/suggest_buys — a multi-PR epic with real ambiguity.

v0.10 ships the **foundation**: a quote-only crypto adapter and a
dedicated `get_crypto_quote` tool. It is self-contained, requires no
schema change, and is reused unchanged if Scope B is later pursued.

## 2. Scope

- **In:** `CryptoQuoteSource` interface + `MercadoBitcoinSource` impl
  (one source — BRL-native, simplest public API).
- **In:** `get_crypto_quote` MCP tool — fetch spot quotes for 1-N
  crypto symbols, with caching + outbound gating + disclaimer.
- **In:** extend `MarketDataCache.put` with an optional `source`
  parameter (default `'brapi.dev'` preserves current behaviour).
- **In:** README + version bump 0.9.0 → 0.10.0 + CI smoke 14 → 15.

- **Out (deferred to a future TODO):** crypto as a tracked
  `asset_class`. Requires schema migration + an import path
  (exchange CSV? manual entry?) that is undefined today. Explicitly
  NOT in this iteration.
- **Out:** Binance and Foxbit sources. The `CryptoQuoteSource`
  interface leaves the door open; v0.10 implements one solid,
  tested source rather than three half-done. YAGNI until a second
  source is actually needed (e.g. an altcoin MB doesn't list).
- **Out:** crypto fundamentals / market-cap rankings / historical
  candles. Spot quote only.
- **Out:** reusing the equity `MarketDataSource` interface. Crypto has
  no `getFundamentals`/`listUniverse` semantics (P/L, dividend yield,
  FII/ACAO/ETF universe). Forcing it would violate Interface
  Segregation. A separate, slimmer interface is correct.

## 3. The Mercado Bitcoin API

Legacy public data endpoint (stable for years, no auth):

```text
GET https://www.mercadobitcoin.net/api/<COIN>/ticker/
```

`<COIN>` is the uppercase symbol, e.g. `BTC`, `ETH`, `SOL`. Response:

```json
{
  "ticker": {
    "high": "352000.00000000",
    "low":  "348000.00000000",
    "vol":  "123.45678901",
    "last": "350000.00000000",
    "buy":  "349900.00000000",
    "sell": "350100.00000000",
    "open": "349000.00000000",
    "date": 1716580000
  }
}
```

- All monetary fields are **strings** in BRL — parse with `parseFloat`.
- `date` is a Unix timestamp in **seconds** — convert to ISO 8601.
- `vol` is volume denominated in the coin (not BRL).
- A symbol MB doesn't list returns an HTTP 4xx or an empty/garbage
  body — map to `TickerNotFoundError` (reused from existing errors).

## 4. Output shape

### 4.1 `CryptoQuote` (source-level)

```ts
export interface CryptoQuote {
  ticker: string;       // "BTC" (uppercased input echoed)
  price_brl: number;    // parseFloat(last)
  high_brl: number;
  low_brl: number;
  buy_brl: number;
  sell_brl: number;
  volume: number;       // in coin units
  updated_at: string;   // ISO 8601 from `date`
  source: string;       // "mercadobitcoin"
}
```

### 4.2 `get_crypto_quote` tool

```ts
const getCryptoQuoteSchema = z.object({
  tickers: z
    .array(z.string().regex(/^[A-Z0-9]{2,10}$/))
    .min(1)
    .max(20)
    .describe("Crypto symbols, uppercase (e.g. ['BTC','ETH']). 1-20."),
  cache_ttl_minutes: z
    .number()
    .nonnegative()
    .optional()
    .describe("Override default TTL (15 min). 0 forces a fresh fetch."),
});

interface PerCryptoResult {
  ticker: string;
  quote: CryptoQuote | null;
  error: { code: string; message: string; recoverable: boolean } | null;
}

export interface GetCryptoQuoteResult {
  ok: boolean;
  source: string;       // "mercadobitcoin"
  results: PerCryptoResult[];
  warnings: string[];   // includes DISCLAIMER
}
```

Mirrors `get_market_data`'s per-ticker partial-failure model: one bad
ticker doesn't fail the batch; its `error` field is populated while
others succeed.

### 5.1 Cache keying

Cache rows are keyed `(ticker, data_type, source)`. Crypto uses
`data_type='crypto_quote'`, `source='mercadobitcoin'`. This cannot
collide with brapi equity quotes (`data_type='quote'`,
`source='brapi.dev'`) even for a same-named ticker. The `cache.get`
lookup keys on `(ticker, data_type)` only — fine, because
`crypto_quote` is disjoint from `quote`/`fundamentals`.

### 5.2 Known debt (documented, not fixed here)

`fetchWithRetry` throws `BrapiTimeoutError` / `BrapiRateLimitError` —
names coupled to brapi. When the crypto path hits a timeout/429, the
error code will read `BRAPI_TIMEOUT` / `BRAPI_RATE_LIMIT`, which is
semantically imprecise in a crypto context. **Not refactored in
v0.10** — renaming the error module would touch the brapi test suite
and is out of scope. Tracked as a follow-up TODO. The `recoverable`
flags are still correct, so client behaviour is unaffected.

## 6. Edge cases

| Scenario | Behaviour |
|---|---|
| Symbol MB doesn't list | `TickerNotFoundError` → per-ticker `error`, batch continues |
| Empty/garbage `ticker` object in response | `TickerNotFoundError` |
| Timeout | `BrapiTimeoutError` (recoverable), surfaced per-ticker |
| 429 rate limit | `BrapiRateLimitError` (recoverable), surfaced per-ticker |
| `cache_ttl_minutes: 0` | force fresh fetch, skip cache read |
| All tickers fail | `ok: true` still (the call succeeded; per-ticker errors populated). Mirror `get_market_data`. |
| Outbound disabled in profile | `OutboundDisabledError` thrown (whole tool) — same as `get_market_data` |

## 7. Tests

### 7.1 `crypto-source.test.ts` (~6 cases)

Mock `fetch` (the source uses `fetchWithRetry` which calls global
`fetch`). Follow the brapi test mocking pattern — read
`src/advisor/market-data/brapi.test.ts` first if it exists.

- Happy path: mock MB response → assert `CryptoQuote` shape, string→
  number parsing, Unix→ISO date conversion.
- Ticker not found: mock 404 or empty `ticker` → `TickerNotFoundError`.
- Price string parsing: `"350000.00000000"` → `350000` (number).
- Date conversion: `1716580000` → correct ISO string.
- Volume parsing: `"123.456"` → `123.456`.
- `source` field is `"mercadobitcoin"`.

### 7.2 `cache.test.ts` extension (~2 cases)

- `put` with explicit `source='mercadobitcoin'` writes that source to
  the row (verify via direct SELECT).
- `put` without `source` arg still writes `'brapi.dev'` (compat).

### 7.3 `get-crypto-quote.test.ts` (~5 cases)

- Happy path: stub `deps.source`, assert result shape + DISCLAIMER.
- Cache hit: pre-seed cache, assert no source call.
- Outbound disabled: profile without outbound → `OutboundDisabledError`.
- Multi-ticker partial failure: one ticker throws, others succeed →
  `ok: true`, mixed `error`/`quote` fields.
- `cache_ttl_minutes: 0`: forces fresh fetch even with a cached row.

### 7.4 Manual smoke (not in CI)

A `describe.skip` or `it.skipIf(!process.env.MB_LIVE)` test that hits
the real MB API for `BTC` and asserts `price_brl > 0`. Runs locally
only — never in CI (no network dependency in CI). Mirrors the real-PDF
fixture pattern from v0.6.
