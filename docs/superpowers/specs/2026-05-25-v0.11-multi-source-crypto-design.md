## 1. Why

Open TODO (2026-05-24, deferred from v0.10 §10): *"Adicionar fontes cripto
Binance/Foxbit atrás da interface `CryptoQuoteSource` (multi-source fallback /
cobertura de altcoins que o Mercado Bitcoin não lista)."*

v0.10 shipped one solid source (`MercadoBitcoinSource`). The gap: altcoins MB
doesn't list. Foxbit (BR, BRL-native) widens BR coverage; Binance (the largest
global exchange) covers the long tail of altcoins — but quotes them in **USDT**,
not BRL, which collides with our BRL-only `CryptoQuote` interface.

User decision (2026-05-25): include **Foxbit + Binance with USD→BRL
conversion**, accepting the FX-rate dependency to actually cover altcoins.

## 2. Scope

- **In:** `FoxbitSource` (BRL-native) behind `CryptoQuoteSource`.
- **In:** `BinanceSource` (USDT-native) that converts every monetary field to
  BRL using a USDT/BRL rate derived from the **already-integrated Mercado
  Bitcoin** `/USDT/ticker/` endpoint (no new external FX dependency).
- **In:** `MultiSourceCryptoQuoteSource` (Composite / Chain-of-Responsibility)
  — tries sources in order, falling through on `TickerNotFoundError` and on
  recoverable errors (timeout/429), returning the first successful quote.
- **In:** additive `CryptoQuote` fields `price_usd?` and `fx_rate_brl_per_usd?`
  for conversion transparency (BRL-native sources leave them undefined).
- **In:** `get_crypto_quote` defaults to the multi-source (was single MB).
- **In:** README + version bump 0.10.0 → 0.11.0.

- **Out:** CCXT or any exchange-aggregation library. Three simple ticker GETs
  don't justify a 100+-exchange dependency (KISS + the project's "no new deps"
  stance). `MercadoBitcoinSource` is the template.
- **Out:** order books beyond best bid/ask, candles, fundamentals.
- **Out:** crypto as a tracked `asset_class` (Scope B — still deferred).
- **Out:** a fiat-FX provider (awesomeapi/exchangerate). The USDT/BRL rate from
  a BR exchange reflects the real crypto-market BRL premium better than an
  official fiat rate, and adds no dependency.

## 3. The APIs

### 3.1 Binance (USDT-native)

```text
GET https://api.binance.com/api/v3/ticker/24hr?symbol=<SYM>USDT
```

Public, no auth. One call returns bid/ask too. All monetary fields **strings**:

```json
{ "lastPrice":"77299.54", "bidPrice":"77299.53", "askPrice":"77299.54",
  "highPrice":"77699.97", "lowPrice":"76108.00", "volume":"8693.73",
  "closeTime":1779713306002 }
```

- `volume` is base-asset units (coin), like MB's `vol`.
- `closeTime` is Unix **milliseconds** → ISO (MB's `date` was seconds — careful).
- Symbol Binance doesn't list → HTTP 400 `{"code":-1121,"msg":"Invalid symbol."}`
  → map to `TickerNotFoundError`.

### 3.2 Foxbit (BRL-native)

```text
GET https://api.foxbit.com.br/rest/v3/markets/<sym>brl/ticker/24hr
```

Public, no auth. **Nested** response:

```json
{ "last_trade": {"price":"...","date":"..."},
  "rolling_24h": {"high":"...","low":"...","volume":"..."},
  "best": {"bid":{"price":"..."}, "ask":{"price":"..."}} }
```

- Market symbol is lowercase `<coin>brl`, e.g. `btcbrl`.
- Unknown market → 404 → `TickerNotFoundError`.

### 3.3 USDT/BRL rate (for Binance conversion)

```text
GET https://www.mercadobitcoin.net/api/USDT/ticker/   → ticker.last ≈ "5.01" (BRL per USDT)
```

Reuses the existing MB path. USDT treated as USD proxy (stablecoin). The
`BinanceSource` fetches this rate once per `getCryptoQuote` call and multiplies.

## 4. Output shape

`CryptoQuote` gains two optional fields (additive — existing consumers unaffected):

```ts
export interface CryptoQuote {
  ticker: string;
  price_brl: number;
  high_brl: number;
  low_brl: number;
  buy_brl: number;
  sell_brl: number;
  volume: number;              // coin units
  updated_at: string;
  source: string;              // "mercadobitcoin" | "foxbit" | "binance"
  price_usd?: number;          // NEW: set only by USDT-native sources (Binance)
  fx_rate_brl_per_usd?: number;// NEW: the USDT/BRL rate used for conversion
}
```

`GetCryptoQuoteResult.source` becomes `"multi"` (the strategy name); the real
source per ticker stays in `quote.source` (already present). Pre-1.0, the
top-level `source` string value changing is acceptable (not enum-typed).

## 5. Architecture

```text
src/advisor/market-data/crypto-source.ts            (EDIT)
  - CryptoQuote: add price_usd?, fx_rate_brl_per_usd?
  - existing MercadoBitcoinSource: unchanged
  - NEW FoxbitSource implements CryptoQuoteSource   (name "foxbit")
  - NEW BinanceSource implements CryptoQuoteSource   (name "binance")
      - constructor takes a UsdBrlRateProvider (default: MB /USDT/ticker/)
      - converts last/bid/ask/high/low by the rate; volume stays in coin
      - sets price_usd + fx_rate_brl_per_usd
  - NEW UsdBrlRateProvider: { getUsdBrlRate(): Promise<number> }
      - MbUsdBrlRate (default) reuses fetchWithRetry against MB USDT ticker
  - NEW MultiSourceCryptoQuoteSource implements CryptoQuoteSource (name "multi")
      - constructor(sources: CryptoQuoteSource[])
      - tries in order; TickerNotFoundError or recoverable error → next source
      - all fail → throw the last error

src/tools/get-crypto-quote.ts                        (EDIT)
  - default source: new MultiSourceCryptoQuoteSource([MB, Foxbit, Binance])
  - result.source = source.name ("multi"); per-quote source unchanged
  - deps.source still injectable for tests

src/index.ts                                         (no change — still 15 tools)
```

### 5.1 Fallback order

`MB → Foxbit → Binance`. BRL-native sources first (no conversion error); Binance
last because its BRL value carries FX-conversion imprecision. A major like BTC
stops at MB; an altcoin MB/Foxbit don't list reaches Binance (USDT→BRL).

### 5.2 Conversion staleness

The USDT/BRL rate has its own freshness; the converted quote uses the **asset's**
`updated_at` (from Binance) and exposes `fx_rate_brl_per_usd` so the consumer can
see the rate applied. We do not over-engineer a dual-timestamp model.

## 6. Edge cases

| Scenario | Behaviour |
|---|---|
| BTC (all sources have it) | MB answers, stop (no Foxbit/Binance call) |
| Altcoin only on Binance | MB 404 → Foxbit 404 → Binance USDT→BRL quote |
| Symbol on no source | last source's `TickerNotFoundError` surfaces per-ticker |
| Binance up, USDT rate fetch fails | `BinanceSource` throws (recoverable) → caught per-ticker; MB/Foxbit already tried |
| Foxbit nested field missing | `TickerNotFoundError` (same guard style as MB) |
| Recoverable error mid-chain (429/timeout) | fall through to next source |
| Outbound disabled | `OutboundDisabledError` (whole tool) — unchanged |

## 7. Tests (TDD)

### 7.1 `crypto-source.test.ts` additions (~14 cases)

- `FoxbitSource`: happy path (nested → flat CryptoQuote), unknown market →
  `TickerNotFoundError`, lowercase market symbol in URL, `source:"foxbit"`.
- `BinanceSource`: happy path (USDT→BRL using a stubbed rate provider; assert
  `price_brl == price_usd * rate`, `price_usd` + `fx_rate_brl_per_usd` set,
  `source:"binance"`), ms→ISO date, invalid symbol → `TickerNotFoundError`,
  rate-provider failure propagates.
- `MultiSourceCryptoQuoteSource`: first source wins (others not called),
  `TickerNotFoundError` falls through to next, recoverable error falls through,
  all-fail throws last error, `name == "multi"`.

- default multi-source wiring (stub the chain), `result.source == "multi"`,
  per-quote `source` reflects the real one.
